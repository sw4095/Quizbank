사진은 저장한 뒤 ‘문제 목록’에서 수정을 눌러 붙일 수 있어요.

‘안 보기’ 설정은 이 기기에만 적용돼요. 다른 사람의 화면에는 영향을 주지 않아요.

관리자 로그인

문제는 누구나 볼 수 있고, 추가·수정·삭제는 이 저장소에 쓰기 권한이 있는 GitHub 토큰으로 로그인한 사람만 할 수 있어요. 토큰은 이 기기의 브라우저에만 저장돼요.

토큰 만드는 방법
  1. GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token
  2. Repository access: Only select repositories → 이 사이트의 저장소 하나만 선택
  3. Permissions → Repository permissions → Contents: Read and write
  4. 생성된 github_pat_… 값을 위 칸에 붙여넣기

관리자로 로그인됨

저장하면 저장소에 바로 기록되고, 다른 사람 화면에는 사이트가 다시 배포된 뒤(보통 1분 안팎) 보여요.
